# 지구마불세계여행 종합 탐구 전광판 (Earth Marble World Travel Project)

초등학교 사회/지리 프로젝트 수업의 마지막 차시에서 모둠별(14개 모둠) 탐구 결과와 갤러리 워크(Gallery Walk)를 통해 발견한 일반화된 문장을 종합·공유하고, 교실 빔프로젝터/전자칠판에 시원하게 띄울 수 있는 웹 애플리케이션 구축 계획입니다.

> [!IMPORTANT]
> **확정된 기본 설계 및 권장 사양 (Default Specifications)**
> 1. **기술 스택**: 사용자 지정 필수 제약에 따라 순수 `index.html`, `style.css`, `script.js` 3개 파일로 분리 구현하여 GitHub Pages에 즉시 100% 호환되도록 제작합니다.
> 2. **모둠 구성**: 기본 14개 모둠 칸을 사전에 프리셋으로 세팅하여 즉시 수업에 투입할 수 있습니다.
> 3. **화면 뷰 모드**: 
>    - **모둠 입력 모드**: 모둠명(나라 이름)과 탐구 일반화 문장을 입력/수정/삭제하는 카드 그리드
>    - **교사 종합 전광판 모드**: 교실 전체 공유용 큼직하고 둥글둥글한 폰트의 전광판 그리드 & 카드 클릭 시 초대형 전체화면 모달 (닫기 버튼 포함)
> 4. **외부 연동 준비**: 상단에 [🔄 시트 불러오기]와 [💾 시트에 결과 저장] 버튼을 구비하고, 로컬 스토리지 자동 저장 및 Google Apps Script 웹앱 연동 스펙을 준비합니다.

## 1. Overview & Core Concept

- **목적**: '지구마불세계여행 프로젝트' 최종 차시에서 모둠별로 특정 국가의 기후, 지형, 인구, 생활모습을 종합 탐구한 후, 갤러리 워크를 통해 도출한 **일반화된 문장**을 학급 전체에 효과적으로 공유.
- **주요 사용자**:
  - **초등학생 (모둠원)**: 직관적이고 친근한 파스텔톤 인터페이스에서 모둠명(나라 이름)과 문장을 작성 및 제출.
  - **초등교사**: 교탁 컴퓨터나 전자칠판에서 전체 14개 모둠의 핵심 문장을 한눈에 관찰하고, 발표 모둠의 문장을 클릭 한 번으로 초대형 전광판 모달로 확대 제시.
- **핵심 가치**: 복잡한 회원가입이나 개인정보 입력 없이, 가볍고 직관적인 순수 웹 기술로 수업 몰입도를 극대화하고 GitHub Pages 배포 지원.

- **디자인 테마**: 산뜻하고 부드러운 세계여행 탐험가 파스텔 테마
  - 배경: 은은한 에어 메일 / 소프트 클라우드 블루 (`#F0F7FF`, `#F9FBFF`)
  - 카드: 부드러운 파스텔 틴트 (민트 `#E8F8F5`, 피치 `#FFF3E0`, 스카이 `#E3F2FD`, 라벤더 `#F3E5F5`)
  - 타이포그래피: 초등학생 눈높이에 맞춘 굵고 둥글둥글한 가독성 높은 폰트 (Pretendard / Jua 웹폰트 폴백 및 고대비 굵은 서체)
  - 전광판 모드: 글자 크기 대폭 확대 (최소 20px~28px), 큰 카드 클릭 시 화면 90%를 채우는 48px급 초대형 발표 모달
- **핵심 인터랙션**:
  - **[모둠 이름 입력 / 수정]**: 모둠별 카드에서 나라 이름 및 일반화된 문장을 즉각 인라인 또는 간편 폼으로 작성
  - **[교사 종합 전광판 전환]**: 상단 토글로 발표 모드로 전환 시, 불필요한 입력 컨트롤이 숨겨지고 시각적 가독성 극대화
  - **[초대형 확대 모달]**: 전광판 카드 클릭 시 화면 전체에 모둠 번호 + 나라명 + 일반화 문장이 역동적인 애니메이션과 함께 등장, 우측 상단 닫기 [✕] 및 키보드 `Esc` 지원
  - **[문장 삭제 / 초기화]**: 작성된 글을 필요시 안전하게 비울 수 있는 [지우기] 버튼 (실수 방지 확인 팝업 포함)

## 3. Key Product Decisions & Trade-Offs

- **순수 3개 파일(HTML/CSS/JS) 독립 구성**:
  - *결정*: 빌드 도구 의존성 없이 브라우저에서 단독 실행 및 GitHub Pages에서 바로 동작하는 순수 `index.html`, `style.css`, `script.js` 작성. Vite 개발 서버와 표준 정적 웹서버 모두 지원하도록 구성.
  - *이점*: 초등학교 교단 PC 환경(망분리, 구형 브라우저, 외부 라이브러리 차단 등)에서도 오류 없이 즉시 열리며 관리가 간편함.
- **데이터 영속성 (localStorage + Google Apps Script 연동 준비)**:
  - *결정*: 1차적으로 브라우저 `localStorage`에 자동 저장되어 새로고침해도 작성 내용이 유지되도록 처리.
  - *이점*: 다음 단계에서 Google Apps Script URL만 입력하면 [🔄 시트 불러오기] 및 [💾 시트에 결과 저장]이 `fetch()` API로 실시간 동기화될 수 있는 클린 아키텍처 구축.
- **불필요한 입력 필드 제거**:
  - *사용자 요구사항 반영*: 기후/지형/생활모습 개별 칸 및 학생 이름 적는 칸을 없애고, **[모둠명/나라명]**과 **[일반화된 문장]**에만 온전히 집중하도록 단순화.

### 실행 검증 계획
1. `index.html`, `style.css`, `script.js` 생성 및 연계 확인
2. 14개 모둠 기본 카드 렌더링 및 모둠명/나라명/문장 입력 테스트
3. [교사 전광판] 토글 시 글자 크기 확대 및 카드 클릭 시 풀스크린 모달 팝업 동작 확인
4. [지우기/삭제] 동작 및 로컬 스토리지 보존 확인
5. [🔄 시트 불러오기] 및 [💾 시트에 결과 저장] 연동 팝업/핸들러 정상 작동 확인
6. Vite 개발 서버 및 빌드(`compile_applet`) 정상 통과 확인

📊 구글 스프레드시트 실시간 연동 설정

타 계정·학생 기기·GitHub Pages 등 어디서 접속하든 100% 실시간 공유되도록 구글 스프레드시트(Apps Script)를 연결합니다.

⚡ 1분 연동 방법:
1) 새 구글 스프레드시트 열기 → 상단 메뉴 [확장 프로그램] > [Apps Script] 클릭
2) 아래 [📋 Apps Script 코드 복사] 버튼을 눌러 기존 코드를 지우고 붙여넣기 후 저장(💾)
3) 우측 상단 [배포] > [새 배포] → 유형: 웹 앱, 액세스 권한: 모든 사용자(Anyone) 선택 후 배포
4) 발급된 웹 앱 URL을 아래 칸에 붙여넣고 저장한 뒤, 상단 [🔗 공유 링크 복사]로 학생들에게 링크 배포!
